# Регрессионный набор реплик (ТЗ, раздел 15.6)

Цель — ловить регрессии маршрутизации: реплика должна либо уходить по быстрому
пути (`hub/local_commands.py`) с конкретной командой, либо отдаваться LLM.

## Как запускать

```
make test-regress
# или
python -m pytest tests/regress -q
```

Порог прохождения — 95% по тем репликам, которые реально выполнились.

## Формат реплики

Файл `fixtures.jsonl`, одна JSON-запись на строку. Поля проверяются строго
(лишние ключи запрещены):

| Поле | Значения | Комментарий |
|---|---|---|
| `id` | уникальная строка | по нему падает тест |
| `language` | `en` / `ru` / `es` | покрытие языков проверяется отдельно |
| `transcript` | текст реплики | уже распознанная речь |
| `expected_route` | `fast_command` / `llm` / `banter` / `not_addressed` | что должно решить ядро |
| `expected_command` | объект или `null` | аргументы инструмента для быстрого пути |
| `audio_file` | путь или `null` | для будущих записанных реплик |
| `notes` | строка | зачем этот случай нужен |

Реплики с `banter` / `not_addressed` пока пропускаются с причиной: для них нужен
живой распознаватель, а не только текстовый роутер.

## Как добавить записанную речь

1. Положите WAV (16 кГц, моно) в `tests/regress/audio/` и укажите имя файла в
   `audio_file`.
2. Заполните `transcript` так, как его должен выдать Whisper, и `expected_route`.
3. Ничего не меняйте в роутере ради прохождения реплики: правится ожидание в
   наборе, а не поведение системы.

Целевой объём по ТЗ — не меньше 100 реплик: 3 языка, шум, перекрытия голосов,
галлюцинации Whisper. Набор доведён до этой планки: 112 записей, из них 102
проверяются текстовым роутером, остальные (болтовня, обращения не к ассистенту)
ждут записанной речи и сейчас пропускаются с причиной.
