# Экономный OpenAI-режим

Реализовано: текстовый Responses API (`gpt-5.6-luna` в активном профиле;
генератор экономного профиля использует `gpt-5.4-mini`), локальные STT/TTS и
зрение, отдельный адрес Ollama для зрения, сохраняемый учёт расходов,
однозначные команды ПК без LLM, короткий промпт и ожидание wake word после
каждого ответа. Новый TTS-движок, объединение нескольких камер и новая модель
идентификации людей ещё не внедрены. Для GPT-5.4 и GPT-5.6 Luna проверены настоящий текстовый
ответ и цикл вызова инструмента; это проверка подключения, не оценка качества всех задач.

## Запуск

Используйте Python окружения `jarvis`. Создание профиля сохраняет адреса,
аудиоустройства и камеры из локального config.yaml и не меняет исходный файл:

```powershell
python scripts/configure_openai.py
```

На этом ПК `config.openai.yaml` уже создан. Повторный запуск генератора
откажется перезаписать файл. Настройки можно редактировать в созданном профиле.

На сервере остановите старый процесс Jarvis и запустите:

Можно открыть `start-jarvis-openai.bat` двойным щелчком либо выполнить:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/run-openai-server.ps1
```

Скрипт использует `OPENAI_API_KEY` из окружения. Если переменная не задана,
он прочитает сохранённый ключ либо один раз запросит его скрытым вводом.
Введённый ключ сохраняется средствами Windows DPAPI в
`%LOCALAPPDATA%\Jarvis\openai-api-key.dpapi`: файл зашифрован для текущей учётной
записи Windows на этом ПК. При следующих запусках вводить ключ не требуется.
Для замены запустите скрипт с `-ReplaceKey`. Ключ не нужно отправлять в чат
или сохранять в YAML; на ПК в зале он не копируется. Для возврата к прежнему
режиму запускайте обычный `scripts/run-server.ps1` с исходным config.yaml.

Сетевой адрес и порт остаются прежними. Если клиент подключается через ngrok,
прежний туннель должен продолжать работать; новый скрипт его не запускает.

На комнатном ПК обновите код из этого проекта и задайте в ЕГО config.yaml:

```yaml
client:
  attention_mode: wake_word
  followup_window_s: 0
```

Это поля внутри существующего client, не замена всего раздела. Затем
перезапустите клиент. Серверный профиль нельзя слепо копировать поверх
клиентского: пути и устройства на двух ПК могут отличаться.

## Как теперь разговаривать

«Rowan, volume 30» → реальная команда → короткое подтверждение → ожидание.
Разговор с друзьями после ответа не записывается как следующая реплика
ассистенту. Каждую новую команду и ответ на уточнение начинайте с «Rowan».
То же правило действует после приветствий и во время регистрации голоса.

Локальный VAD передаёт серверу только событие наличия речи в комнате,
чтобы отложить автоматическое приветствие, пока люди разговаривают.
Это не транскрипция фонового разговора и не облачный вызов. Он не определяет
адресата по взгляду или смыслу, а wake word всё ещё может ложно сработать.
Если обращение и речь другу слиты в одну фразу без паузы, строгий режим сам
по себе не разделит их. Статусы HUD показывают, когда ассистент слушает.

`attention_mode: window` возвращает прежние follow-up окна (максимум 30 секунд).
Для общей комнаты этот режим не рекомендуется.

Локальные быстрые команды: числовое изменение громкости, mute/unmute,
громче/тише, следующий/предыдущий трек, открытие Chrome/Firefox/Spotify/Steam/
Notepad/Calculator. Неоднозначные и составные запросы идут модели. Проверки
прав человека сохраняются. «Пауза» пока не включена в быстрый путь: существующая
клавиша play/pause переключает состояние и не гарантирует остановку музыки.

## Расходы

Профиль ограничивает учтённые расходы $18 за календарный месяц UTC, оставляя
запас до желаемых $20. Журнал — `data/api_usage.sqlite3`; не удаляйте его для
«сброса» лимита. Цена учитывается отдельно для модели каждого запроса:
GPT-5.4 — $2.50 / 1 млн входных и $15 / 1 млн выходных токенов;
GPT-5.4 mini — $0.75 / $4.50 соответственно. Подтверждённые API кэшированные
входные токены считаются по $0.25/M для GPT-5.4 и $0.075/M для mini.
До исправления 2026-09-20 эти две модели учитывались без скидки за кэш;
исторические оценки не пересчитываются без исходных сведений о кэше.
GPT-5.6 Luna — $0.20 / $1.20 соответственно; кэшированный вход $0.02,
запись в кэш $0.25 за миллион токенов. Резерв Luna покрывает запись всего
входа в кэш; итог пересчитывается по `cached_tokens` и `cache_write_tokens`
из ответа API. Если детализация отсутствует, сохраняется консервативная оценка.
Источник: [OpenAI Docs для Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna).
Тарифы проверены 2026-09-18 по [OpenAI Docs](https://developers.openai.com/api/docs/models/gpt-5.4).
При смене модели прежние расходы и незавершённые резервы сохраняются.
При исчерпании лимита остаются локальные быстрые команды; произвольный
облачный диалог недоступен до следующего месяца или изменения настройки.

Сетевой таймаут не возвращает резерв, потому что запрос мог быть оплачен.
Повторы, тул-раунды, параллельные подключения учитываются отдельно. После
неопределённого сбоя лимит может сработать раньше, чем показывает счёт OpenAI.
Лимит приложения не учитывает расходы других программ, налоги или изменение
тарифа. Для этого ассистента используйте отдельный API-проект.

Проверить локальный учёт без сети:

```powershell
python scripts/api_usage.py
```

## Проверка на настоящем оборудовании

После ввода ключа проверить обычный вопрос, действие, отказ инструмента,
запрос о камере/экране и прерывание по wake word. Затем поговорить с другом
после ответа: новых транскрипций, действий и API-запросов быть не должно.
Проверить также, что приход человека во время беседы не вызывает немедленного
приветствия. Качество микрофона, распознавание личности и желаемый голос
нуждаются в отдельной проверке на реальных образцах.
